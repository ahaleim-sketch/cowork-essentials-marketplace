# Thumbnail Generator

Generate scroll-stopping thumbnail concepts backed by competitor research. Every concept comes with a full visual brief you can hand to a designer or build yourself.

## How It Works

When you say "generate thumbnails for [topic]" or "thumbnail ideas for [video title]", this skill runs a three-step process: research, generate, recommend.

## Step 1: Competitor Research

Before designing anything, research what already exists:

1. **Search YouTube** for the top 10-20 videos on the same topic
2. **Screenshot or describe** the thumbnail patterns you see
3. **Identify overused patterns** -- what does everyone do? (these are what you avoid)
4. **Identify gaps** -- what is nobody doing? (these are your opportunities)
5. **Note standouts** -- which thumbnails made YOU want to click? Why?

Document findings in a quick table:

| Pattern | Frequency | Overused? | Notes |
|---------|-----------|-----------|-------|
| Face + bold text | 8/10 | Yes | Everyone does this |
| Before/after split | 2/10 | No | Could stand out |
| Dark bg + glow | 6/10 | Yes | Feels generic now |

## Step 2: Generate 5 Concepts

Create 5 thumbnail concepts, each using a DIFFERENT style from this list:

| Style | Description | Best For |
|-------|-------------|----------|
| **Bold Text + Face** | Large text, expressive face, solid bg | Reaction, opinion, story videos |
| **Before/After** | Split screen showing transformation | Tutorials, reviews, makeovers |
| **Clean Minimal** | One icon or object, minimal text, lots of space | Premium/luxury feel, tech |
| **Comparison** | Two things side by side, VS energy | Versus videos, alternatives |
| **Dark + Glow** | Dark bg, neon or glowing accent elements | Tech, gaming, AI topics |
| **Screenshot + Arrow** | Screen capture with red arrow/circle | How-to, bug fixes, tips |
| **Editorial** | Serif font, warm tones, magazine feel | Thought pieces, essays |
| **Icon Trap** | Single large icon, notification badge, minimal text | Curiosity gap, "what is this" |
| **Number Stack** | Big number, stacked items below | Listicles, rankings, collections |
| **Emotion Close-Up** | Extreme close-up face, one word | Dramatic, controversial takes |

## Step 3: Full Concept Brief

For EACH of the 5 concepts, provide:

### Concept [Number]: [Style Name]

**Layout:** Describe exact placement of every element (left/right/center, top/bottom)

**Background:** Color or gradient with hex codes (e.g., dark teal #0A2A2A)

**Text:**
- Exact words (5 words MAX -- this is non-negotiable)
- Font style (bold sans, serif, condensed, etc.)
- Color with hex code
- Size relative to canvas (e.g., "takes up 40% of width")

**Visual Elements:**
- What images, icons, screenshots, or faces appear
- Exact placement and approximate size
- Any effects (drop shadow, glow, border, badge)

**Color Palette:**
- Primary: #hex
- Accent: #hex
- Text: #hex
- Background: #hex

**Why It Works:** One sentence on the psychology (curiosity gap, pattern interrupt, emotion trigger, etc.)

## Thumbnail Rules (Non-Negotiable)

1. **5 words max** on any thumbnail -- if you need more, you need a better concept
2. **High contrast** -- must be readable at mobile size (120x68 pixels)
3. **One focal point** -- the eye should go to exactly one place first
4. **No clutter** -- every element must earn its place. When in doubt, remove it
5. **Emotion over information** -- thumbnails sell a feeling, not a summary
6. **Test at small size** -- shrink it mentally. Can you still read it? Still get the idea?
7. **Avoid stock photo energy** -- nothing should look generic or template-y

## Final Recommendation

After presenting all 5, recommend your top 2 for A/B testing:

**A/B Test Recommendation:**
- **Option A:** [Concept #] -- Best for [reason]. This will likely get more clicks from [audience type].
- **Option B:** [Concept #] -- Best for [reason]. This takes a different angle that could outperform with [audience type].

Explain WHY these two are the strongest pair. A good A/B test uses two genuinely different approaches, not two variations of the same idea.
