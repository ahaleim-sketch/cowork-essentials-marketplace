# LinkedIn Post Writer

Turn any idea, experience, article, or content into a LinkedIn post optimized for engagement. Works for any industry — tech, consulting, creative, finance, healthcare, whatever your professional world is.

## Instructions

### Step 1: Understand the Input

The user might give you:
- A topic or idea ("write about hiring mistakes")
- An experience ("I just lost a client and learned something")
- An article or content to repurpose
- A hot take or opinion
- A milestone or achievement

Check CLAUDE.md for the user's industry, role, and voice if available.

If the input is too vague, ask: **"What's the one thing you want the reader to take away from this post?"**

### Step 2: Choose the Post Format

Pick the format that best fits the content:

| Format | Structure | Best For |
|--------|-----------|----------|
| **Story** | Hook → Problem → Journey → Lesson → Takeaway | Personal experiences, failures, wins |
| **Listicle** | Hook → Numbered list → CTA | Tips, mistakes, tools, frameworks |
| **Hot Take** | Contrarian statement → Evidence → Reframe → Invite discussion | Opinions, industry commentary |
| **Before/After** | Old way → New way → What changed → How you can too | Transformations, process improvements |
| **Lesson Learned** | Situation → What happened → What I learned → Apply it | Mistakes, realizations, aha moments |
| **Framework** | Problem → Your framework/model → How it works → Try it | Thought leadership, unique methods |
| **Carousel Setup** | Hook → "Here are the X slides" → Key points → CTA | If user wants carousel content |

### Step 3: Write the Post

**LinkedIn Formatting Rules:**

| Rule | Why |
|------|-----|
| Hook in the first 2 lines | LinkedIn truncates at ~210 characters. Everything after is behind "see more." |
| One sentence per line | LinkedIn doesn't render paragraphs well. Single lines with spaces between them read better. |
| Short sentences (under 15 words) | Skimmers read fast. Short sentences survive the scroll. |
| Use line breaks generously | White space makes posts readable on mobile. |
| No hashtags in the body | Put 3-5 hashtags at the very end, separated by a blank line. |
| End with engagement prompt | Ask a question or invite a response. LinkedIn's algorithm rewards comments. |
| 150-300 words ideal | Long enough to deliver value, short enough to finish. |

**Post Template:**

```
[Hook — 1-2 lines that stop the scroll. Use a bold claim, surprising stat, contrarian take, or relatable frustration.]

[Blank line]

[Setup — 2-3 lines of context. What happened? What's the situation?]

[Blank line]

[Body — The meat. 5-10 lines with the actual insight, story, or framework. Use numbered lists, bold text, or short paragraphs.]

[Blank line]

[Takeaway — 1-2 lines. The one thing you want them to remember.]

[Blank line]

[CTA — Ask a question or invite engagement. "What's your experience with this?" / "Drop your go-to tool below." / "Agree or disagree?"]

[Blank line]

#hashtag1 #hashtag2 #hashtag3
```

### Step 4: Hook Library

If the user needs inspiration, use one of these hook patterns:

| Pattern | Example |
|---------|---------|
| Contrarian opener | "Unpopular opinion: meetings are not the problem." |
| Personal failure | "I lost my biggest client last month. Here's what I learned." |
| Surprising stat | "80% of proposals get ignored. Here's why yours does too." |
| Direct address | "If you're a freelancer charging hourly, read this." |
| Before/after | "2 years ago I had 0 clients. Today I turned down 3 this week." |
| Question | "What's the one habit that changed your career?" |
| Bold claim | "Cold email is dead. Here's what replaced it." |

### Step 5: Quality Check

Before presenting, verify:
- [ ] Hook is compelling in under 210 characters (before "see more")
- [ ] Every line adds value — cut anything that's filler
- [ ] Written in the user's voice, not generic LinkedIn-speak
- [ ] Has a clear takeaway — reader knows the point
- [ ] Ends with an engagement prompt
- [ ] 3-5 relevant hashtags at the bottom
- [ ] No emojis overload (0-3 max, or none if the user prefers clean)

### Step 6: Present and Offer Variations

Show the post, then offer:
- "Want a shorter version? (under 100 words)"
- "Want me to write 2 more variations with different hooks?"
- "Should I adapt this as a carousel outline?"

## Output

A complete, ready-to-post LinkedIn post. Clean text the user can copy directly into LinkedIn's editor.
