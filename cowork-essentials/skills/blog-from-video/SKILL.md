# Blog Post from Video

Turn any video transcript into a well-structured, SEO-friendly blog post. Paste a transcript or describe the video — and get a complete blog post that reads naturally (not like a transcription).

## Instructions

### Step 1: Get the Source Material

Accept any of these inputs:
- A pasted transcript
- A file path to a transcript
- A video URL (note: you can summarize what the user tells you about the video, but you cannot watch videos)
- A description of what the video covers

If the user just says "turn my latest video into a blog post" with no transcript, ask: "Paste the transcript or give me a summary of what the video covers."

### Step 2: Analyze the Content

From the transcript/summary, identify:

- **Main topic** — What is this video fundamentally about?
- **Key sections** — What are the 3-7 main points or segments?
- **Audience level** — Beginner, intermediate, or expert?
- **Unique insights** — What does this video say that a generic Google result doesn't?
- **Quotable moments** — Any memorable phrases or strong statements worth preserving?
- **Actionable takeaways** — What can the reader DO after reading?

### Step 3: Restructure for Reading

Transcripts are spoken word — they don't read well as-is. You must restructure:

| Spoken Pattern | Written Equivalent |
|----------------|-------------------|
| Rambling intro with "so basically..." | Tight 2-sentence hook |
| Tangents and asides | Cut or move to a sidebar/note |
| Repeated points for emphasis | State once, clearly |
| "Like I said before..." | Remove — readers can scroll up |
| Filler ("you know", "basically", "right?") | Delete entirely |
| Conversational transitions ("okay so next...") | Clean section headers |

### Step 4: Write the Blog Post

**Structure:**

```
# [SEO-Friendly Title — Include Primary Keyword]

[Hook — 2-3 sentences that tell the reader what they'll learn and why it matters. Not "In this blog post I'll cover..." — make it compelling.]

## [Section 1 Header]
[Content — 2-4 paragraphs. Include specifics, examples, and actionable details.]

## [Section 2 Header]
[Content]

## [Section 3 Header]
[Content]

[Continue for all major sections...]

## Key Takeaways
- [Takeaway 1 — one sentence]
- [Takeaway 2 — one sentence]
- [Takeaway 3 — one sentence]

---

*[Optional: "This post was adapted from [a video / my YouTube channel]. Watch the full video here: [link placeholder]"]*
```

### Step 5: Quality Rules

| Rule | Why |
|------|-----|
| Rewrite, don't transcribe | A blog post is not a transcript with headers |
| Front-load value | Best insight in the first 3 paragraphs, not buried at the end |
| Use headers for scannability | Readers skim — headers let them jump to what they care about |
| Include specific examples | "Use Canva to resize" not "use a design tool" |
| Add formatting variety | Mix paragraphs, bullet lists, bold text, and quotes |
| SEO basics | Primary keyword in title and first paragraph. Headers as H2/H3. |
| Natural tone | Should read like a knowledgeable friend explaining, not a textbook |
| 800-1500 words typical | Long enough to be valuable, short enough to finish |

### Step 6: Present and Offer Extras

Show the complete blog post, then offer:
- "Want me to generate 3 meta description options for SEO?"
- "Should I create a shorter version for LinkedIn or Medium?"
- "Want me to add internal/external links?"

## Output

A complete, ready-to-publish blog post in clean markdown. Formatted with proper headers, lists, and emphasis.
