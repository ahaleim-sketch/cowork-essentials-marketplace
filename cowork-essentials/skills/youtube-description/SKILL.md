# YouTube Description & Tag Generator

Generate a fully optimized YouTube description and tag set from a video transcript or script. The description is designed for discoverability, click-through, and watch time. The tags target a healthy mix of short-tail and long-tail keywords.

## Instructions

### Step 1: Receive the Transcript

Accept the user's input in any of these formats:
- Full video transcript (pasted or file path)
- Finished video script
- Bullet-point outline of what the video covers
- A topic plus key points

If the input is too vague (just a title or one sentence), ask: "Can you share the full transcript or at least a detailed outline of what the video covers?"

### Step 2: Analyze the Content

Before writing anything, extract the following from the transcript:

1. **Primary topic** — What is the single main subject?
2. **Secondary topics** — What supporting topics or tools are mentioned?
3. **Key moments** — Major sections, transitions, or highlights (for timestamps)
4. **Tone** — Is the video casual, professional, tutorial-style, review, storytelling, hype?
5. **Tools/products mentioned** — Every specific tool, app, platform, or product named
6. **Target audience** — Who is this video for? Beginners, pros, a specific niche?
7. **Core value proposition** — What does the viewer gain by watching?

### Step 3: Generate the Description

Write the description in this exact structure:

```
[Opening hook — 1-2 sentences that appear in search results. Must include the primary keyword naturally. This is the most important line for SEO. Make it compelling enough to click.]

[Blank line]

[2-3 sentence summary expanding on what the video covers. Match the tone of the video. Keep sentences short and scannable.]

[Blank line]

⏱ Timestamps
0:00 - Intro
[X:XX] - [Section name]
[X:XX] - [Section name]
[X:XX] - [Section name]
[Continue for all major sections]

[Blank line]

🔗 Links & Resources
[List every tool, product, or resource mentioned with its URL if known]
[If URLs are unknown, write the tool name and leave a placeholder: (link)]

[Blank line]

[Optional: 1-2 sentence call to action — subscribe, comment, check out a community, etc. Only include if it fits naturally.]
```

**Description rules:**
- The first 150 characters are critical — they show in search results. Front-load the primary keyword.
- Match the video's tone. If the video is casual, the description should be casual. If it is a tutorial, be direct and instructive.
- Keep it scannable. Short paragraphs, line breaks, emoji section headers.
- Timestamps are mandatory for videos over 5 minutes. For shorter videos, include them only if there are clear distinct sections.
- Never stuff keywords unnaturally. The description should read like a human wrote it.
- Include 1-2 relevant hashtags at the very end (e.g., #AItools #productivity).

### Step 4: Generate Tags

Produce 15-20 tags following these rules:

**Tag mix:**
- 3-4 broad/short-tail tags (high volume, high competition): e.g., "AI tools", "productivity"
- 5-7 medium-tail tags (moderate volume): e.g., "best AI tools 2026", "Claude tutorial"
- 5-7 long-tail tags (low competition, high intent): e.g., "how to use Claude Cowork for beginners", "free AI tools for content creators"
- 2-3 brand/tool-specific tags: e.g., "ChatGPT", "Notion AI", "CapCut"

**Tag rules:**
- No tag longer than 30 characters when possible (YouTube truncates long tags).
- Do not repeat the exact same phrase in multiple tags.
- Include common misspellings or alternate names if relevant (e.g., "chat gpt" and "chatgpt").
- Put the most important tags first — YouTube gives slight priority to earlier tags.
- Never use misleading or irrelevant tags.

### Step 5: Present the Output

```
## YouTube Description

[Full description text]

---

## Tags

[Comma-separated tag list]

---

## SEO Notes
- **Primary keyword:** [the main keyword targeted]
- **Search intent:** [what someone searching this wants]
- **Competitor note:** [one observation about how to stand out in search results for this topic]
```

### Step 6: Offer Refinement

After presenting, ask:
> "Want me to adjust the tone, add/remove timestamps, or target a different keyword?"

## Tips for Best Results

- The more transcript detail you provide, the better the timestamps and tag targeting will be.
- If you have a specific keyword you want to rank for, mention it and the description will be optimized around it.
- For shorts (under 60 seconds), skip timestamps and keep the description to 2-3 sentences plus tags.
